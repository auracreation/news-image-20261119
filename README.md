## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The script writes the finished front page (`entry.png`, 1024×1024) to the
directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`). The image is
pre-rendered and ships beside the program, so the run is a pure byte copy —
deterministic by construction.
